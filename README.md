# PLACEHOLDER UAV — GitHub Pages Static Website

This is a pure HTML/CSS/JavaScript website. No backend is required.

## Quick deployment

1. Create a GitHub repository, e.g. `uav-global`.
2. Upload all files and folders in this project.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/root`.
4. Your site will be available at `https://YOUR_USERNAME.github.io/uav-global/`.

## Replace these placeholders first

Search the project for:
- `PLACEHOLDER`
- `SALES_EMAIL`
- `WHATSAPP_NUMBER`
- `+XX XXX XXX XXXX`
- `PLACEHOLDER BUSINESS ADDRESS`
- product names/specifications
- product image placeholder blocks

## Custom domain later

Buy a domain such as `yourbrand.com`, then configure the GitHub Pages custom domain in repository Settings → Pages. DNS records can be managed through your registrar or Cloudflare.

## Form

The quote form currently opens the visitor's email client using `mailto:`. For a real lead collection workflow, replace it later with Formspree, Web3Forms, Basin, a Google Form, or your own backend.
